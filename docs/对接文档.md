# 云 PSDK 功能测试前端需求文档

## 1. 概述
本文档用于说明“云 PSDK 功能测试前端”的页面需求与 MQTT 对接协议，面向前端研发与对接测试人员。

## 2. 目标 / 范围 / 约束 / 非目标

### 目标
- 提供用于 PSDK 功能测试的前端页面。

### 范围
- MQTT 连接配置与状态展示。
- PSDK 在线状态与浮窗信息展示。
- 喊话器相关功能控制（音频播放、TTS、重播、停止、播放模式、音量）。
- 指令调用结果展示。

### 约束
- 操作尽可能简单方便。
- 页面简洁美观。
- 无需显示原始的消息内容（不直接展示 JSON）。

### 非目标
- 不涉及后端实现或 PSDK 端实现细节。

## 3. 技术栈
- vite + react-ts + mqtt + React 组件框架（待选）

## 4. 页面结构与功能模块
1. 连接配置区：输入 MQTT 连接参数（具体字段待确认）以及 gatewaySn、deviceSn。
2. 连接状态区：展示 MQTT 连接状态与 PSDK 在线状态。
3. 浮窗信息区：展示最新浮窗文本内容（不展示原始 JSON）。
4. 功能控制区：音频播放、TTS 播放、重播、停止、播放模式、音量设置。
5. 结果提示区：展示每次指令的成功/失败状态与结果码。

## 5. 用户流程与交互步骤
1. 进入页面。
2. 填写 MQTT 连接参数与 gatewaySn、deviceSn。
3. 建立 MQTT 连接。
4. 订阅相关 Topic。
5. 展示 PSDK 状态与浮窗信息。
6. 下发功能指令。
7. 等待 reply 返回。
8. 展示指令调用结果。

## 6. PSDK 状态维护

### 6.1 在线判定
若 PSDK 在线，会定时推送 PSDK 浮窗的 MQTT 消息。可根据“最近一次浮窗消息时间”判断在线状态：
- 在线：在阈值内收到浮窗消息。
- 离线：超过阈值未收到浮窗消息。
- 未知：尚未收到任何浮窗消息。

> 在线判定阈值：待确认。

### 6.2 psdk-浮窗文本推送

## 7. 通用字段说明（根据示例归纳）
以下字段含义为根据示例归纳，最终以对接方定义为准：

| 字段       | 含义（归纳）                       | 备注 |
| ---------- | ---------------------------------- | ---- |
| bid        | 业务/请求标识（示例中为 UUID）      |      |
| tid        | 事务/跟踪标识（示例中为 UUID）      |      |
| timestamp  | 毫秒级时间戳                        |      |
| gateway    | 网关标识（示例中为 gateway_sn）      |      |

## 8. 功能对接协议（MQTT）
每次下发功能指令需等待消息返回，并提示指令是否调用成功。

### 8.1 psdk-开始播放音频

**请求**

**Topic**: thing/product/{gateway_sn}/services

**Direction**: down 

**Method**: speaker_audio_play_start

**Data**:

| Column      | Name                                  | Type        | constraint         | Description             |
| ----------- | ------------------------------------- | ----------- | ------------------ | ----------------------- |
| psdk_index  | psdk 负载设备索引                     | int         | {"min":0}          | 固定为 2 (机身上方云台) |
| file        | 音频文件                              | struct      |                    |                         |
| file.name   | 文件名                                | text        | {}                 |                         |
| file.url    | 文件下载链接                          | text        | {}                 |                         |
| file.md5    | 音频文件的md5校验和, 用作机场唯一标识 | text        |                    |                         |
| file.format | 喊话器输入文件格式                    | enum_string | {"pcm":"pcm 格式"} |                         |

```json
{
  "bid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "tid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "timestamp": 1689912303287,
  "method": "speaker_audio_play_start",
  "data": {
    "file": {
      "format": "pcm",
      "md5": "b38257017001f45ec064b5157b2e4416",
      "name": "20230720162718",
      "url": "https://example.com/5a6f9d4b-2a38-4b4b-86f9-3a678da0bf4a/3dd27366-bf21-41a7-9f07-62b74f2e93a7/fe2f2474-720a-4122-a552-010e1ed08920/20230720162718.webm.pcm"
    },
    "psdk_index": 2
  }
}
```

**应答**

**Topic:** thing/product/*{gateway_sn}*/services_reply

**Direction:** up

**Method:** speaker_audio_play_start

**Data:**

| Column | Name       | Type | constraint | Description |
| ------ | ---------- | ---- | ---------- | ----------- |
| result | 结果返回码 | int  |            |             |

**Example:**

```json
{
	"bid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxx",
	"data": {
		"result": 0
	},
	"tid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxx",
	"timestamp": 1654070968655,
	"method": "speaker_audio_play_start"
}
```
